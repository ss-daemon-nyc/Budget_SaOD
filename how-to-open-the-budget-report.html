How to Open the Budget Report

The report is a single file named budget-breakdown.html. It opens in the same program you use to look at websites. There is nothing to install and no password needed.

✅ You cannot break anything. The report is read-only — clicking around only changes what you see on your own screen. It does not need the internet after you have the file, and it never changes the real budget numbers.

Step 1 — Save the file to your computer

  1. Open the email that has the report attached.
  2. Click the attachment named budget-breakdown.html.
  3. Choose Download or Save if you are asked.
    The file usually lands in your Downloads folder.

Step 2 — Open it

  1. Open your Downloads folder.
    On Windows: open File Explorer (the yellow folder icon), then click Downloads on the left.
    On a Mac: open Finder (the smiling face icon), then click Downloads on the left.
  2. Double-click the file budget-breakdown.html.
  3. The report opens in your web browser — Chrome, Edge, Safari, or Firefox. Whichever you have is fine.
If double-clicking opens the wrong program: click the file once with the right mouse button, choose Open with, and pick your web browser from the list.

Step 3 — Looking around the report

  • The big numbers at the top are the summary: total budget, what has been spent (posted), what is promised on orders (encumbered), and what is left.
  • Rest your mouse pointer on any bar in the charts — a small card appears with the exact dollar amounts. No clicking needed.
  • The buttons near the top (All expenses · Personnel · OTPS) narrow everything down to one kind of spending. Click All expenses to go back.
  • The table at the bottom lists every account. Click a column heading (for example Posted to GL) to sort by it. Type in the search box to find one account.
  • If the text is too small, hold the Ctrl key and tap + a few times (on a Mac, ⌘ Cmd and +).

When you are done

Just close the browser window. You can double-click the file again any time — it will still be in your Downloads folder.
